1. Authentication

Authenticate all API requests by providing your bot's API key in the standard Authorization HTTP header: 

Authorization: Bearer bot_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

2. Rate Limits 🚦

The Bot API enforces a limit of 120 requests per minute per bot API key. When exceeded, the server returns HTTP 429 Too Many Requests with a Retry-After header.

3. Send a Message

POST /api/v1/bots/messages/send

cURL Example:

curl -X POST http://127.0.0.1:8000/api/v1/bots/messages/send \
  -H "Authorization: Bearer bot_live_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient_username": "alice",
    "text": "Hello Alice! Your study reminder is ready."
  }'

Python Example:

import requests

url = "http://127.0.0.1:8000/api/v1/bots/messages/send"
headers = {
    "Authorization": "Bearer bot_live_YOUR_KEY_HERE",
    "Content-Type": "application/json"
}
payload = {
    "recipient_username": "alice",
    "text": "Hello from Python Bot!"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

JavaScript / Node.js Example:

const fetch = require('node-fetch');

async function sendBotMessage() {
  const res = await fetch('http://127.0.0.1:8000/api/v1/bots/messages/send', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer bot_live_YOUR_KEY_HERE',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      recipient_username: 'alice',
      text: 'Hello from Node.js Bot!'
    })
  });
  const data = await res.json();
  console.log(data);
}

sendBotMessage();

4. Webhook Signatures & Security

When webhook events are sent to your callback server, they include cryptographic headers to verify authenticity:

  • X-Funchat-Bot-Signature: sha256=<hmac_hex_digest>
  • X-Funchat-Timestamp: <unix_timestamp>

Verifying in Python:

import hmac
import hashlib

def verify_webhook(raw_payload_bytes, signature_header, secret):
    expected_sig = "sha256=" + hmac.new(secret.encode(), raw_payload_bytes, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected_sig, signature_header)
